# EWU StudyHub Logo Generation Prompt

Create a modern, minimal academic logo for **EWU StudyHub**, a student-focused academic resource and marketplace platform for East West University students in Bangladesh.

### Visual direction
- Inspired by an academic / university identity, but **do not copy or recreate the East West University logo, crest, wordmark, or protected visual elements**.
- Create an original symbol that combines the idea of a **study hub + organized academic resources + digital learning**.
- Use a simple geometric icon that remains recognizable at very small sizes.
- Optional visual ideas: an abstract open book, linked pages, a study node/network, or a subtle hub/circle motif.
- Clean SaaS/product aesthetic rather than a traditional university seal.
- Professional, trustworthy, modern, friendly, student-focused.
- Suitable for a web header, mobile app icon, favicon, social profile, resource cards, and printed promotional material.

### Primary version
- Deep navy as the main brand color.
- White as the primary background.
- Teal as the secondary accent.
- Flat vector style, crisp edges, no 3D mockup, no photographic effects.

### Deliverables
1. Horizontal logo: icon + “EWU StudyHub” wordmark.
2. Compact icon-only mark for favicon/mobile header.
3. Transparent background PNG.
4. Clean SVG-style vector look.
5. Also provide a monochrome dark and monochrome light variant.

### Typography
Use a clean modern sans-serif wordmark. “EWU StudyHub” should be highly legible on a mobile screen.

### Avoid
- Exact EWU logo recreation
- Official university crest or seal
- Graduation-cap clipart as the only concept
- Overly complex details
- Excessive gradients
- Tiny unreadable text inside the icon
- Generic stock-logo appearance

Generate a polished, original brand identity that feels like a **premium academic student platform**, with the icon strong enough to work without the wordmark.
